# 🐍 Basic Python Input and Arithmetic Operations

## 📋 Overview

This Python script demonstrates two fundamental programming tasks:

- **Task 1:** Performing basic arithmetic operations (addition, subtraction, multiplication, division) on two user-provided numbers.
- **Task 2:** Accepting user input for first and last names and displaying a personalized greeting message.

---

## 🧠 Features

### ✅ Task 1: Arithmetic Operations

- Prompts the user to input two integers.
- Performs and displays:
  - Addition
  - Subtraction
  - Multiplication
  - Division

### ✅ Task 2: Personalized Greeting

- Prompts the user to input their first and last names.
- Displays a friendly welcome message using the provided names.

---

## 🛠️ Requirements

- Python 3.x

No external libraries are required.

---

## 🚀 How to Run

1. Save the script as `basic_tasks.py`.
2. Open a terminal or command prompt.
3. Run the script using:

```bash
python basic_tasks.py
```

4. Follow the on-screen prompts to enter numbers and your name.
